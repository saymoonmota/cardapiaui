# 📸 Instruções para os Prints

Salve os prints das telas com exatamente estes nomes nesta pasta:

| Arquivo | Tela a capturar |
|---|---|
| `home.png` | https://cardapiaui.netlify.app/ |
| `cardapio.png` | https://cardapiaui.netlify.app/cardapio |
| `modal.png` | Cardápio com modal de um prato aberto |
| `login.png` | https://cardapiaui.netlify.app/login |
| `sobre.png` | https://cardapiaui.netlify.app/sobre |
| `contato.png` | https://cardapiaui.netlify.app/contato |
| `admin.png` | https://cardapiaui.netlify.app/admin (logado) |

Depois de salvar os arquivos aqui, rode no terminal:

```
git add .
git commit -m "docs: adiciona prints das telas"
git push origin main
```
